### Exercise: Secure Login System
Build a file-based authentication system

Requirements: <br>
• User data storage: Read username/password from users.txt <br>
• Login validation: Check credentials against file data <br>
• Session logging: Log all login attempts (success/failure) <br>
• Error handling: Handle missing files, invalid input, file corruption <br>
• Security: Don't expose passwords in error messages<br>
Reflection Questions:<br>
• How does proper exception handling improve user experience?<br>
• Which Programming Principles did you apply?<br>
• How would you extend this system for a real application?<br>
